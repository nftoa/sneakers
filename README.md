# Sneakers
![Alt Text](assets/sneakers.jpg)
Template Web Sneakers adalah project frontend yang dibuat sebagai bagian dari proses rekrutmen kerja. Dibangun dalam waktu 1 hari sebagai technical test, project ini menampilkan landing page toko sepatu sneakers dengan layout modern, daftar produk, dan struktur UI yang responsif.
